* Kontak Off

langkah-langkah
1. Colokan OBD
2. Tekan tombol star stop (On-Acc-Off-On-Acc-Off)
3. Tutup pintu-buka pintu-tutup pintu-buka pintu (respon hazard menyala)
4. Tempelkan lambang pada remote ke tombol star stop (CDL bergerak 2x)
5. Cabut OBD
6. Cek fungsi remote

Catatan

Registrasi Remote kunci manual
Pastikan!
* Kontak Off
* Pintu depan kanan terbuka
langkah-langkah
1. Cabut kunci kontak
2. Cabut soket fuse box (1 menit)
3. Sambung soket fuse box
4. Colok kunci kontak dan cabut lagi
5. Lock-Unlock CDL 3x
6. Tutup pintu dan buka lagi (respon Hazard menyala)
7. Tekan tahan tombol unlock remote 1 samapai CDL bergerak 2x
8. Tekan tahan tombol unlock remote 2 samapai CDL bergerak 2x
9. Cek fungsi remote
